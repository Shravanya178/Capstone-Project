# Integration Guide for Sanket (Modules 7–10: Safety & Treatment Planning)

## 1. Executive Summary
This guide explains how Sanket's contraindication assessment, patient safety, and treatment recommendation modules ingest the outputs generated by Shravanya's modules (Modules 1–7).

## 2. Integration Contracts & Schema Locations

| Artifact | File Location | Schema Specification | Consumer Purpose |

## 3. How Sanket Consumes the Patient Profile

```python
import json
import jsonschema

# 1. Load patient profile JSON
with open("data/sample/sample_patient_profile.json", "r") as f:
    patient_profile = json.load(f)

# 2. Extract key clinical parameters
patient_id = patient_profile["patient_id"]
biomarkers = patient_profile["pathology_biomarkers"]
er_status = biomarkers["er_status"]          # 'positive', 'negative', 'er_low', 'equivocal', 'not_reported'
her2_status = biomarkers["her2_status"]      # 'positive', 'negative', 'equivocal', 'not_reported'
subtype = biomarkers["molecular_subtype"]    # 'luminal_a', 'luminal_b_her2_negative', 'her2_enriched', 'triple_negative', etc.

# 3. Check review flags for critical missingness or equivocal results
review_flags = patient_profile["review_flags"]
for flag in review_flags:
    print(f"[{flag['severity'].upper()}] {flag['field']}: {flag['message']}")
```

## 5. Explicit Invariants & Non-Duplication Agreement

1. **Missing Data Invariant**:
   - Shravanya guarantees that missing parameters are NEVER implicitly imputed to negative or normal. If a biomarker is missing, its status is explicitly `not_reported`.
2. **Equivocal HER2 Invariant**:
   - IHC 2+ cases without confirmatory ISH are strictly flagged with `result: "requires_review"`. Sanket's contraindication engine must not recommend anti-HER2 therapies until ISH confirmation is recorded.
3. **Temporal Segregation Invariant**:
   - Shravanya guarantees that post-treatment surgical resection observations (`timepoint: "post_treatment_resection"`) and neoadjuvant trial outcomes (`timepoint: "outcome"`) are segregated from baseline parameters.
4. **Boundary of Responsibilities**:
   - **Shravanya does NOT** implement drug-drug interactions, organ toxicity thresholds (e.g., creatinine clearance, LVEF cutoffs), multi-criteria regimen scoring, or patient preference ranking.
   - **Sanket owns** all drug contraindication filtering, patient safety gates, and final treatment recommendation ranking.
